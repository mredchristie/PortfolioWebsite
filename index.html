Secure Package Registry (SPR)

Final Year Project, Cardiff University

A preventative security layer for the npm and Go Modules ecosystems that vets packages before they reach developers, not after. SPR is an event-driven, service-oriented registry where every package version undergoes sandboxed behavioural analysis, provenance verification, and reproducible builds before being promoted to the curated registry. It closes the gap that tools like Snyk and npm audit leave open: the window between a malicious publish and detection.

▸ eBPF-based behavioural analysis via Tracee on GitHub Actions runners, capturing syscalls, file access, network connections, and DNS; HTTPS traffic decrypted using ecapture without being detectable by the package under test
▸ Reproducible builds and provenance verification (upstream attestation, OSS rebuild, or in-house reproducible build) to detect source-to-release tampering
▸ 0–3 trust score combining behavioural results and provenance signals, with manual review override for enterprise compliance and a policy-based registry proxy blocking untrusted pulls
▸ Dual Gitea registry model: curated spr-registry for approved packages and isolated spr-sandbox for analysis; package managers point at SPR with no workflow changes
▸ RabbitMQ-driven pipeline (poller → core-svc → be-runner) with full dependency tree resolution and transitive mirroring before sandboxed execution
▸ Addresses real-world attacks including event-stream (2018), xz-utils backdoor, and ua-parser-js compromise, covering the broader class of threats existing tools miss

CS2Price

A real-time CS2 skin price aggregator that polls multiple third-party marketplaces (Skinport, Waxpeer, DMarket, CSFloat, Buff163) and presents the cheapest listings per skin in a single searchable interface. Built to eliminate the tedium of comparing prices across tabs manually.

▸ Polls 5 marketplaces on configurable cron schedules, storing normalised USD prices in PostgreSQL
▸ Authenticated DMarket API integration with signed request handling
▸ Buyer/Seller fee toggle showing what you pay versus what the seller receives after platform fees
▸ Float value bar with accurate condition zone markers (FN/MW/FT/WW/BS) aligned to real float boundaries
▸ Fallback search links on every card guarantee 3+ marketplace links even when no live listing exists
▸ FX rate refresh via Frankfurter API; skin images via ByMykel community API
SvelteKit TypeScript Node.js PostgreSQL Redis Docker
