Self-Hosted Infrastructure

20 containers, a mail server and a VPN on one 2 GB droplet...

0111. The Architecture

Everything on this page runs on a single DigitalOcean droplet in London with 2 GB of RAM, deliberately kept small and cheap. A host nginx terminates TLS for every subdomain and proxies to containers bound to localhost, while the mail server and VPN take their traffic directly. The portfolio site you're reading is the exception: it's static, served from Cloudflare R2 so it stays up even if the droplet doesn't.

1000. What's Running

Mox Mail Server

Fully self-hosted email for @mredchristie.dev: SMTP, IMAP and webmail from a single Go binary running directly on the host, with SPF, DKIM, DMARC and MTA-STS configured so mail actually lands in inboxes. DigitalOcean blocks outbound port 25, so outgoing mail relays through SMTP2GO over port 8465 while inbound mail arrives directly.

Mox SMTP / IMAP DKIM / DMARC SMTP2GO

Reverse Proxy & TLS

A single host nginx fronts every service: 11 subdomains, each with a Let's Encrypt certificate auto-renewed by certbot. App containers bind only to localhost ports, so nothing is reachable except through the proxy, and adding a new service is one site file and one DNS record.

nginx certbot Let's Encrypt

WireGuard VPN

Personal VPN into the droplet using wg-easy, with peer management through a web UI. Useful for a trusted exit point on public Wi-Fi and for reaching admin interfaces without exposing them publicly.

WireGuard wg-easy Docker

Application Stacks

The live projects each run as Docker Compose stacks: the weather and surf apps as single containers with persistent volumes, CS2Price as a five-container stack (web, poller, Postgres, Redis, autoheal), and the Secure Package Registry as its full ten-container production deployment including Gitea, RabbitMQ and MinIO - all inside the same 2 GB memory budget.

Docker Compose PostgreSQL Redis RabbitMQ Gitea MinIO

Monitoring & Management

Uptime Kuma checks every service and feeds the public status page linked in the navigation bar, so you can see for yourself when something is down. Portainer provides a management UI over the Docker daemon for quick inspection and restarts.

Uptime Kuma Portainer

This Site: Static on R2

The portfolio itself is deliberately boring: hand-written HTML, CSS and vanilla JavaScript mirrored to a Cloudflare R2 bucket by a one-line deploy script. No build step, no server, nothing to fall over - if the droplet has a bad day, this page doesn't.
